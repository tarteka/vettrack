# FrontEnd (Angular)

FrontEnd para VetTrack desarrollado en Angular.

## Levantar proyecto

> Primero levantamos el proyecto backend para que cree la red que necesitamos.

Copiamos el archivo de ejemplo de variables de entorno:

```bash
cp .env.example .env
```

Levantamos contenedores:

```bash
docker compose --profile dev up -d
```

Accedemos con nuestro navegador a http://localhost:4200/.
